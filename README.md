# SecureFileMonitor

## Project Overview
SecureFileMonitor is a Python-based file monitoring and integrity checking project. It helps monitor files, check file integrity, maintain a baseline, and generate security-related reports.

## Features
- File monitoring
- File integrity checking
- Baseline file management
- Security alerts
- Audit report generation

## Technologies Used
- Python
- Kali Linux
- Git and GitHub

## Project Files
- `file_monitor.py` – File monitoring
- `integrity_check.py` – File integrity checking
- `baseline.json` – Baseline data
- `security_alert.py` – Security alerts
- `audit_report.py` – Audit report generation

## How to Run
1. Clone or download this repository.
2. Open the project folder in Kali Linux.
3. Run the Python scripts using Python 3.
